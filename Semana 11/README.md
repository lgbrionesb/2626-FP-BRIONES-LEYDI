# Semana 11: Búsqueda y ordenación de elementos en arreglos multidimensionales

**Estudiante:** Leydi Briones

## Descripción

Este programa trabaja con una matriz de 5 filas por 5 columnas. Solicita al usuario 25 valores numéricos, almacena cada valor en su posición correspondiente y muestra la matriz completa organizada en forma de tabla.

## Ejecución

Desde la carpeta del repositorio, ejecuta:

```bash
python "Semana 11/matriz5x5.py"
```

El programa utiliza bucles anidados para recorrer las filas y columnas, ingresar los datos y mostrar el resultado final.

## Evidencia de entrega

La entrega debe incluir el archivo Python, el enlace al repositorio público de GitHub y una captura de pantalla donde se observe la ejecución y la matriz resultante.
