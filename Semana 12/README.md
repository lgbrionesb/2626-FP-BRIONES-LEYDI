# Semana 12: Reserva de un asiento en sala de cine

**Estudiante:** Leydi Briones

## Descripcion

Este programa representa una sala de cine pequeña con 3 filas y 4 columnas. Cada asiento se almacena en una matriz como `0` si esta libre o `1` si esta reservado. El usuario indica la fila y la columna del asiento que desea reservar, y luego se muestra el estado completo de la sala.

## Ejecucion

Desde la carpeta del repositorio, ejecuta:

```bash
python "Semana 12/reserva_cine.py"
```

Las filas validas son `0`, `1` y `2`, mientras que las columnas validas son `0`, `1`, `2` y `3`.
