## Descripcion

Este programa resuelve un problema de la vida real: calcular el total de una compra. La funcion `calcular_total` recibe dos parametros, el precio del producto y la cantidad adquirida, realiza la multiplicacion y retorna el resultado.

## Ejecucion

Desde la carpeta del repositorio, ejecuta:

```bash
python "Semana 13/calcular_compra.py"
```

Con los datos de ejemplo (`precio = 10` y `cantidad = 3`), el programa muestra un total de `$30.00`.
