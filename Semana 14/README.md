# Semana 14: Funciones con parámetros y retorno de valores

**Estudiante:** Leydi Briones

## Contexto y objetivo

Esta actividad aplica el uso de funciones con parámetros y retorno de valores
mediante un problema sencillo de la vida real: calcular el promedio de tres
notas.

## Descripción del programa

El programa solicita tres notas al usuario y llama a la función
`calcular_promedio`. Esta función recibe las tres notas como parámetros, calcula
el promedio y utiliza `return` para devolver el resultado. Finalmente, el
programa muestra el promedio en pantalla con dos decimales.

El código incluye:

- Una función llamada `calcular_promedio`.
- Tres parámetros de entrada.
- La palabra clave `return`.
- Una llamada a la función.
- La impresión del resultado en pantalla.

## Ejecución

Desde la carpeta del repositorio, ejecuta:

```bash
python "Semana 14/calcular_promedio.py"
```
