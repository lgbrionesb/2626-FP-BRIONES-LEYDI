# Semana 15: Tarea practica - Colecciones de datos

**Estudiante:** Leydi Briones

## Contexto y objetivo

Esta actividad aplica el uso de colecciones de datos mediante un programa
sencillo para administrar contactos. Se utiliza un diccionario para relacionar
el nombre de cada contacto con su numero telefonico.

## Descripcion del programa

El programa presenta un menu que permite agregar, mostrar, buscar y eliminar
contactos. No permite registrar nombres vacios ni duplicados, y la busqueda se
realiza sin distinguir mayusculas de minusculas.

## Ejecucion

Desde la carpeta del repositorio, ejecuta:

```bash
python "Semana 15/administrar_contactos.py"
```
